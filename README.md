# Visual Schedule Maker — free demo

A free, click-through demo of **Visual Schedule Maker**, an offline app by SoloStack Creations for making picture schedules, First-Then boards, choice boards, token boards and routine cards.

Open the demo: the GitHub Pages address for this repository.

The demo uses made-up example boards. Nothing you make is saved, and printing is switched off. The full app is a single file you download from Etsy and keep on your own computer.

Personal and classroom organising tool. Not therapy, not a medical device.
